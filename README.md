# RielTrack Android downloads

RielTrack is an offline-first money tracker for USD and Cambodian riel.

## Download

[Download the latest signed APK](https://github.com/hongrinrasmey/RielTrack-Downloads/releases/latest/download/RielTrack-1.0.0.apk)

Requires Android 8.0 (API 26) or newer. Download the APK on your device and open it. If Android asks, allow installs from the browser or file manager used to open the file. Android may display an install warning because this APK is distributed directly, outside Google Play.

The release includes `SHA256SUMS.txt` so you can verify the downloaded APK. RielTrack stores transactions and planning data on the device; the app has no sign-in or cloud service. Use the in-app JSON backup to move or preserve your data.

See the release notes for the features included in each version.
