## Why RielTrack

- **Built for Cambodia.** Record every amount in USD or riel. Mixed totals use your own USD/KHR rate, so balances match how you actually pay.
- **Private by design.** No account, no cloud, no analytics, no ads. Android's automatic cloud backup is turned off; you choose when to make a backup file.
- **Works offline.** Everything runs on the phone, so it is fast and always available.
- **English and ភាសាខ្មែរ.** Use English, Khmer, or your phone's language.

## Install

1. On your Android phone, tap the download link above.
2. Open the downloaded `RielTrack-1.0.4.apk`.
3. If Android asks, allow your browser or file manager to install apps.
4. Open RielTrack. No sign-up needed.

RielTrack is installed directly, not through Google Play, so Android may show a warning before installing. Requires Android 8.0 (API 26) or newer.

**Updating:** install the new APK over the old one. Your data stays, because every version is signed with the same key. Make a backup in Settings before changing phones or uninstalling: uninstalling deletes the app's data.

**Verify your download (optional):** each release includes a `SHA256SUMS-<version>.txt` file. Its checksum should match your downloaded APK.
